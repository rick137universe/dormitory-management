# ResidenceEngine

Named export with props progress?: number (default 0, clamped 0–1), mode?: number, compact?: boolean. SVG viewBox 0 0 640 640, responsive width, unique useId gradients. Dark circular engine visual, architectural three-tier isometric residence. Coral upper housing, lime middle repair, lavender lower billing tier. At progress zero tiers assemble into a single building; at one upper tier moves (-20,-100), middle remains, lower moves (20,100). Transform attributes, no inline styles. Dotted vertical connectors fade in during separation. Right-side SVG tier labels appear after .3 progress. Many illuminated windows have engine-window class. Outer multicolor ring group engine-orbit, tick group engine-ticks, orbital bead group engine-satellite have CSS transform origin 320px 320px and transform-box view-box; opacity decreases with progress. mode optionally emphasizes one tier; compact renders a reduced detail presentation. No remote assets. Parent controls progress and Anime.js animation.

Final behavior: optional onSelect(floor) prop; SVG groups expose keyboard-focusable buttons when supplied. Mouse click, Enter and Space open corresponding services. Unique useId gradient ids permit hero and scroll instances.
