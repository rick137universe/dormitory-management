# Dorma requirements map

Source: `3组02241330李冠杰-学生公寓住宿与报修管理系统-需求文档(2).docx`

## Roles

- Student: personal profile, accommodation applications, bill payment, repairs, notices.
- Dorm manager: assigned-building data, accommodation review and bed allocation, repair review, bill checks.
- Maintenance staff: assigned work orders, processing updates, repair records, personal statistics.
- System administrator: global data, workflow control, dispatch, analytics, permissions, backups.

## Eight core modules

1. Personal center
2. Basic information
3. Accommodation workflows
4. Bed status
5. Billing and payments
6. Repair lifecycle
7. Analytics
8. System administration
