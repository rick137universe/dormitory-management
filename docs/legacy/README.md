# 早期原型资料

此目录保存当前 Dorma 页面之前的设计参考和实验实现，便于追溯设计过程。当前应用代码位于 `src/components/dorma/home/` 和 `src/components/dorma/workspace/`，本目录不参与构建和日常验证。

| 目录 | 内容 |
| --- | --- |
| `design-references/` | 早期参考页面截图 |
| `research/` | 早期提取结果、设计说明和 3D 公寓方案 |
| `ui/` | 当前页面已不再引用的旧版组件及模拟数据 |
| `scripts/` | 早期生成、修补和 QA 一次性脚本 |

`output-plan.json` 及脚本中保留了旧目录和开发者机器上的绝对路径，仅用于历史参考。不要在当前代码上直接运行这些脚本。旧 QA 截图和结果可以从 Git 历史查看；新生成的 `docs/qa/` 内容不纳入版本控制。
